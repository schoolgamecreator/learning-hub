# Security & Community Safety Policy

## Reporting Safety & Security Issues

We take platform security, student safety, and community wellbeing seriously. If you encounter a security vulnerability, safety issue, or policy violation, please report it immediately.

### Say Something Anonymous Reporting System
We utilize the **Say Something** reporting program to allow students, parents, and community members to submit anonymous safety concerns, threats, or platform risks.

* **Direct Email Alerts:** All tips, safety alerts, and vulnerability reports submitted through the Say Something platform are automatically encrypted and forwarded directly to our primary response team at **security@example.com** (replace with your actual admin/security email).
* **Emergency Routing:** Urgent reports regarding immediate threats to safety or platform integrity are flagged for priority review upon receipt.

### What to Include in a Report
When submitting a report via Say Something or direct email, please include:
* A description of the security issue, safety concern, or code violation.
* The specific URL, feature, or game involved.
* Step-by-step instructions or proof of concept to help us reproduce the issue.
* Relevant screenshots or error logs (ensuring no personal student data is included).

## Community Rules & Code of Conduct

To maintain a safe learning environment, all users must follow these conduct rules across all games, forums, and interactive features:

### 1. Zero Tolerance for Verbal Abuse and Cursing
* **Appropriate Language Only:** Profanity, foul language, slurs, and offensive words are strictly prohibited across all usernames, game chats, and user inputs. Automated filters actively block vulgarity.
* **No Verbal Abuse or Harassment:** Bullying, trash-talking, personal attacks, hate speech, and harassment of any kind will result in an immediate account suspension or permanent ban.

### 2. Protection of Personal Information (PII)
* **No Sharing of Personal Details:** Users are strictly forbidden from sharing personal identifiable information—including full names, phone numbers, home addresses, email addresses, social media handles, or school names—in game chats, profiles, or public fields.
* **Automated Data Protection:** Interactive features actively filter out patterns resembling phone numbers, street addresses, and emails to prevent accidental exposure of personal data.

## Platform Security & Data Protection

To safeguard user accounts and game integrity, the platform enforces the following baseline technical controls:

### 1. Data Privacy & Compliance
* **Minimal Collection:** We do not collect unnecessary personal data from students or players.
* **Encryption Standards:** All traffic is encrypted in transit using **TLS 1.2+ (HTTPS)**. User data is encrypted at rest using AES-256 standards.
* **Student Privacy Compliance:** Built to align with COPPA and FERPA privacy standards for educational environments.

### 2. Game & Application Defense
* **Server-Side Game Validation:** Score tracking, leaderboards, and game logic are validated on the server to prevent score tampering, memory editing, or cheat scripts.
* **Content Security Policy (CSP):** Strict CSP headers prevent Cross-Site Scripting (XSS) and block unauthorized third-party scripts or game embeds.
* **Input Sanitization:** All text fields are sanitized to protect against SQL Injection (SQLi) and script injections.

### 3. Account Security
* **Password Hashing:** User passwords are encrypted using modern, salted hash algorithms (Argon2 / bcrypt).
* **Secure Sessions:** Authentication cookies use `HttpOnly`, `Secure`, and `SameSite` flags to guard against session hijacking.
